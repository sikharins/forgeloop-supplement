คุณคือผู้ออกข้อสอบวัดความสามารถของผู้ช่วย AI สำหรับ **บุคลากรห้องสมุดมหาวิทยาลัยในประเทศไทย** ข้อสอบนี้ต้องเป็นชุดใหม่ที่ไม่ซ้ำกับชุดฝึกซึ่งคุณไม่เคยเห็น (ชุดฝึกใช้หัวข้อ: อีเมลแจ้งปิดชั้น 3, บันทึกขออนุมัติซื้อหนังสือพยาบาล, ตอบเรื่องค่าปรับ, โพสต์อบรม Zotero, แปลเชิญวิทยากร, สรุป IFLA AI statement, นโยบาย AI, รายงานประชุม, สถิติบริการ 12 เดือน, คู่มือบริการ 15 หน้า, Project Brief อบรม AI literacy / co-working / IR, งบสัปดาห์หนังสือ, เวลาเปิดทำการ, ACRL AI competencies, PULINET 2027, ข่าวหอสมุด, Koha, APA 7, MARC 21, PubMed MeSH, Open Access, แปลบทคัดย่อ, โปสเตอร์สัปดาห์ห้องสมุด, อินโฟกราฟิกยืมหนังสือ, ภาพบรรณารักษ์กับ AI, ไอคอน 4 บริการ, แก้ภาพวิวหน้าต่าง) — **ห้ามใช้หัวข้อเหล่านี้ซ้ำ** ให้คิดสถานการณ์อื่นในงานห้องสมุดที่ต่างออกไป

ออกข้อสอบ **24 ข้อ** ใน 6 หมวด หมวดละ 4 ข้อ:
- C1 งานเขียนเชิงสำนักงาน (อีเมล หนังสือราชการ ประกาศ ข้อความประชาสัมพันธ์ แปล)
- C2 สรุปและสกัดสาระจากไฟล์แนบ (ต้องมีไฟล์แนบ: ให้คุณเขียนเนื้อหาไฟล์มาด้วย)
- C3 วางแผนโครงการ (Project Brief, งบประมาณ, แผนงาน)
- C4 อ่านเว็บและข้อมูลปัจจุบัน (ให้ URL สาธารณะจริงของห้องสมุดหรือองค์กรวิชาชีพที่เปิดอ่านได้ ไม่ต้อง login)
- C5 ความรู้วิชาชีพและเทคนิค (การลงรายการ การอ้างอิง การสืบค้น มาตรฐานห้องสมุด ไอทีห้องสมุด)
- C6 ภาพประชาสัมพันธ์ (สร้างภาพ 3 ข้อ แก้ภาพ 1 ข้อ — ข้อแก้ภาพให้ระบุว่า "ใช้ภาพห้องสมุดสัญญาอนุญาต CC0 ที่ผู้วิจัยเตรียมให้" และใส่ `"attachments": ["CC0_LIBRARY_PHOTO"]`)

กติกาสำคัญ:
1. ข้อมูลทุกอย่างเป็นข้อมูลสมมติ ใช้ชื่อหน่วยงาน "สำนักหอสมุด มหาวิทยาลัยตัวอย่าง (นามสมมติ)" ห้ามใช้ชื่อบุคคลจริง เบอร์โทรจริง หรือข้อมูลภายในขององค์กรใด
2. **ทุกข้อต้องตรวจด้วยโปรแกรมได้โดยไม่ใช้คนและไม่ใช้ AI**: `gold` ต้องมีอย่างน้อยหนึ่งอย่างต่อไปนี้ (ใส่ได้หลายอย่าง)
   - `"must_contain": ["ข้อความที่ต้องปรากฏ", ...]` (ตรวจแบบมีคำนี้อยู่ ไม่สนตัวพิมพ์/ช่องว่าง)
   - `"must_not_contain": ["ข้อความที่ห้ามปรากฏ หรือข้อมูลที่แต่งขึ้นที่พบบ่อย", ...]`
   - `"numbers": {"ชื่อค่า": 12345, ...}` ตัวเลขที่ต้องปรากฏถูกต้อง
   - `"exact_lines": ["บรรทัดที่ต้องตรงตัวอักษร", ...]` เช่น รายการอ้างอิง
   - `"items": [{"name": "รายการที่ต้องสกัดได้", "aliases": ["คำสะกดอื่น"]}, ...]` สำหรับคำนวณ precision/recall
   - `"image_text": ["ข้อความไทยที่ต้องอยู่ในภาพ"]` (ผู้วิจัยพิมพ์ข้อความที่เห็นในภาพให้สคริปต์คำนวณอัตราตัวอักษรผิด)
   - `"snapshot_urls": [...]` สำหรับหมวด C4 พร้อม `"must_contain"` ที่จะตรวจกับ snapshot วันสอบ
   `checklist` ยังใส่ได้สำหรับให้กรรมการ AI ตรวจเสริม แต่คะแนนหลักมาจาก `gold`
3. หมวด C2 ให้เขียนเนื้อหาไฟล์แนบเป็น Markdown ความยาว 1–4 หน้า A4 ต่อไฟล์ และฝัง "คำตอบที่เดาไม่ได้" ไว้กลางเอกสาร อย่างน้อย 1 ข้อให้มีตัวลวงใกล้เคียง
4. หมวด C4 ระบุ URL จริง และบอกว่าตรวจคำตอบกับ "snapshot ของหน้าเว็บวันรันสอบ"
5. อย่างน้อย 1 ข้อเป็นงาน 2 รอบในแชทเดียว (`turns` มี 2 ข้อความ) และอย่างน้อย 2 ข้อตั้งใจมีข้อมูลขาด เพื่อดูว่าผู้ช่วยแต่งข้อมูลเองหรือไม่ (ใส่ใน checklist ว่า "ไม่แต่งข้อมูลที่ไม่ได้ให้")
6. ห้ามใส่ชื่อโมเดลหรือชื่อผลิตภัณฑ์ AI ใดในโจทย์

ส่งผลลัพธ์เป็น JSON เดียวตามสคีมานี้เท่านั้น (ห้ามมีข้อความอื่นนอก JSON):

```json
{
  "_meta": {"version": "heldout-v1", "author": "GPT", "created": "YYYY-MM-DD", "n": 24},
  "tasks": [
    {
      "id": "H01",
      "cat": "C1 งานเขียนเชิงสำนักงาน",
      "title": "ชื่องานสั้นๆ",
      "turns": ["ข้อความคำสั่งรอบที่ 1 ตามตัวอักษร", "(ถ้ามี) ข้อความรอบที่ 2"],
      "attachments": ["H05/filename.md"],
      "preset": "general | project-brief-builder | web-reader | image-studio",
      "features": {"web_search": true} ,
      "na_arms": [],
      "scoring": {"type": "rubric+checklist | rubric+exact | rubric+numeric | rubric+pr | rubric+snapshot | rubric+cer",
                  "rubric": ["ความถูกต้อง", "ความครบถ้วน", "คุณภาพภาษาไทย", "ความพร้อมใช้"]},
      "checklist": ["ข้อความตรวจได้ 1", "..."],
      "gold": {},
      "snapshot_urls": [],
      "materials_md": {"H05/filename.md": "เนื้อหาไฟล์แนบทั้งหมดเป็น Markdown (เฉพาะหมวด C2)"}
    }
  ]
}
```

ค่า `preset` และ `features` ให้ใช้ตามหมวด: C1, C2, C5 → `"general"` + `{"web_search": true}`; C3 → `"project-brief-builder"` + `{}`; C4 → `"web-reader"` + `{"web_search": true}`; C6 → `"image-studio"` + `{"image_generation": true}` และ `"na_arms": ["L0"]`
