# ForgeLoop: เอกสารเสริมของบทความ

เอกสารเสริมของบทความ "ForgeLoop: การปรับปรุง Harness ของ Local LLM สำหรับงานห้องสมุดแบบวนซ้ำโดยใช้โมเดล Frontier ชี้แนวทาง"
(ForgeLoop: Frontier-Guided Iterative Harness Refinement for a Local LLM in Library Work) หอสมุดและคลังความรู้มหาวิทยาลัยมหิดล

| โฟลเดอร์/ไฟล์ | เนื้อหา |
|---|---|
| `judge/judge-prompt.md` | คำสั่งและเกณฑ์ให้คะแนน 4 ด้านที่ส่งให้กรรมการ AI (ChatGPT และ Gemini) ทุกแชต |
| `judge/ocr-prompt.md` | คำสั่งให้กรรมการถอดข้อความภาษาไทยในภาพ เพื่อคำนวณอัตราตัวอักษรผิด (CER) |
| `judge/chat-message.txt` | ประโยคที่ผู้วิจัยพิมพ์ในทุกแชตหลังแนบไฟล์งาน |
| `exam-generation/exam-generation-prompt.md` | ข้อกำหนดที่ใช้ให้ ChatGPT สร้างชุดสอบ 24 ข้อ |
| `system-prompts/before/`, `system-prompts/after/` | คำสั่งกำหนดบทบาท (system prompt) ฉบับเต็มของผู้ช่วยทั่วไป ผู้ช่วยอ่านเว็บ และผู้ช่วยวาดภาพ ก่อนและหลังกระบวนการ ForgeLoop |
| `system-prompts/project-brief-builder-changes.md` | ส่วนของคำสั่งกำหนดบทบาทของ Project Brief Builder ที่กระบวนการแก้ (ก่อนและหลัง) |
| `harness-settings.md` | ค่าตั้งของ harness ที่เปลี่ยนระหว่างก่อนกับหลังกระบวนการ |

ไม่เผยแพร่โจทย์และเฉลยของชุดสอบ เพื่อให้ใช้สอบซ้ำได้โดยไม่ปนเปื้อน

การส่งงานให้กรรมการ: สคริปต์รวบรวมโจทย์ ไฟล์แนบ เกณฑ์อ้างอิง และคำตอบของทุกกลุ่ม ปกปิดชื่อกลุ่มเป็นตัวอักษรและสุ่มลำดับคนละชุดต่อกรรมการ
จัดเป็นไฟล์งานแชตละหมวด (9 แชตให้คะแนนและ 3 แชตถอดข้อความในภาพต่อกรรมการ) ผู้วิจัยเปิดแชตใหม่ทางหน้าเว็บ แนบไฟล์งาน แล้วพิมพ์ประโยคใน `judge/chat-message.txt`
กรรมการ: ChatGPT (หน้าเว็บแสดงชื่อรุ่น GPT-6 Luna High, โหมด Temporary Chat) และ Gemini 3.1 Pro ทั้งสองไม่ได้ปิดการค้นเว็บ
