# คำสั่ง: ถอดข้อความในภาพ

ภาพที่แนบมี <จำนวนภาพ> ภาพ แต่ละภาพมีแถบสีเทาด้านบนเขียนว่า "LABEL IMGxx" ซึ่งเป็นรหัสภาพที่ผู้จัดเติม — ไม่ต้องถอดข้อความในแถบนี้
ให้ถอดข้อความทุกตัวอักษรที่ปรากฏในส่วนภาพ (ใต้แถบ) ของแต่ละภาพแยกกัน ทีละบรรทัดตามที่เห็นจริง
- พิมพ์ตามรูปที่เห็นทุกตัวอักษร แม้จะสะกดผิด สระหรือวรรณยุกต์หาย/เกิน หรือเป็นอักษรเพี้ยน — ห้ามแก้ให้ถูก ห้ามเดาคำที่ควรจะเป็น ห้ามอิงภาพอื่น
- ตัวที่อ่านไม่ออกให้ใส่ ? แทน 1 ตัว · ไม่ต้องบรรยายภาพ · ถ้าภาพไม่มีตัวอักษรเลย ให้เป็น []

ตอบเป็น JSON อย่างเดียว คีย์คือรหัสภาพ ใส่ครบทุกภาพ (<รหัสภาพ>):
```json
{"IMG01": ["บรรทัดที่ 1", "บรรทัดที่ 2"], "IMG02": ["..."]}
```
